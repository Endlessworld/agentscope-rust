# 会话摘要 2026-08-28

## 目标
修复 AcpCodingAgent ACP 流式输出问题：多个工具调用之间的思考/文本积累到下一次工具调用才推送。

## 诊断结论
问题根因不在 ACP 层（session.rs 逐事件即时 emit、agent-client-protocol 无界 channel 即时发送均无缓冲），
而在 `crates/agentscope-core/src/model/openai.rs` 的 `OpenAiChatModel::stream()`：
`StreamAccumulator` 把整个 SSE 流累积到流末才产出一个完整 `ChatResponse`，破坏逐 token 流式，
且 `accumulate` 从不填充 thinking 字段导致思考内容被丢弃。

## 完成修复
- 重写 `OpenAiChatModel::stream()`：用 `create_stream_byot::<OpenAiStreamChunk>` 逐 chunk 产出增量
  `ChatResponse`（text/thinking 逐个增量块），tool_calls 片段累积到流末完整产出。
- 新增 `OpenAiStreamChunk`/`OpenAiStreamChoice`/`OpenAiStreamDelta`（捕获 `reasoning_content`）、
  `StreamIncrementer` 结构。
- 新增 2 个单元测试验证增量 text/thinking 与 tool_calls 累积。

## 验证
- cargo test -p agentscope-core --lib model::openai：9 通过（含 2 新增）。
- cargo build -p agentscope-harness：通过（仅既有死代码 warning）。

## 影响
- openai.rs：stream() 重写、StreamAccumulator→StreamIncrementer、新增自定义 chunk 反序列化。
- 其余文件未改动。
