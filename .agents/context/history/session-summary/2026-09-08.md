# 2026-09 会话摘要：MCP 工具接入 ReActAgent + ACP 客户端 MCP 支持

## 目标
完成 MIGRATION_GAP_TRACKER §4.2 P1 前两项：McpTool e2e 接入 ReActAgent + ACP 客户端 MCP 支持。

## 完成工作
1. **McpClientManager 工具发现**：`connect()` 握手后调用 `request_tool_list()` 填充
   `client.tools`（此前恒为空）；新增 `find_client_id_by_server`/`call_tool_by_server`。
2. **core McpTool 异步 handler**：新增 `async_handler` 字段 + `with_async_handler()` +
   `McpAsyncHandler` 类型别名；`call()` 优先 await async handler，解决 tokio 运行时内
   `block_on` panic（"Cannot start a runtime from within a runtime"）。
3. **桥接函数**：`bridge_mcp_tools_to_toolkit(&McpClientManager, &Toolkit)` 把已连接
   server 工具注册为 core `McpTool`。
4. **ACP 客户端 MCP 支持**：`AcpAgentSession::apply_mcp_servers(&[McpServer])` 解析 stdio
   声明、连接 + 桥接到会话 Toolkit（幂等去重）；NewSession/LoadSession/ResumeSession 均已接入。
5. **测试**：`harness_mcp_bridge_test`（2 测试）真实 e2e（Node stdio MCP server 发现→桥接→调用）。
