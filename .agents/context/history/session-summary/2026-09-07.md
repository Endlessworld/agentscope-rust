# 2026-09-07 会话摘要：ACP harness agent 执行 git 命令超时排查

## 结论（已实证）
1. **shell 执行链路本身正常**：`SandboxBackedFilesystem::execute`（pwsh -EncodedCommand + spawn/wait + taskkill /T）直接跑 `git status`/`git log` 均 0.6s 内完成，无超时。
2. **发现一个真实 bug（次要）**：`shell_execute_tool.rs::command_with_working_directory()` 在 Windows 下生成 cmd 语法 `cd /d "..." && ...`，但执行器是 pwsh——pwsh 将 `cd /d "path"` 解析为 `Set-Location /d <path>` 报错 "A positional parameter cannot be found"。应改为 pwsh 语法（如 `Set-Location -LiteralPath '...' ; cmd`）。
3. **未能在端到端 ACP 驱动中复现"超时"**：自写 stdio driver 的 initialize 因 protocolVersion 需 u16 而失败；session/prompt 因 sessionId 不匹配返回 refusal，未走通完整工具调用路径。工具层默认超时为 ExecutionConfig::tool_defaults() = 300s（5 分钟），非 30s。
