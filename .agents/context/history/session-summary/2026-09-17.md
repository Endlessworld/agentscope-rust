# 2026-09-17 会话摘要：B1 Docker 沙箱后端（最后一个 P0）

## 目标
完成 `MIGRATION_GAP_TRACKER`（docs/harness 版）B1：Docker Sandbox 后端（DockerSandbox / Client / Options / State）。

## 关键决策
- **不引 `bollard`**，改用 `docker` CLI —— 与 Java 参考实现（`DockerSandbox` 用 `ProcessBuilder` + docker CLI）逐行对齐，且不增 daemon API 依赖。详见 `history/adr.md` ADR-001。

## 完成工作
1. 新增 `crates/agentscope-harness/src/agent/sandbox/docker.rs`（~880 行）：
   - `DockerSandboxClient`：create（从 options 建 DockerSandboxState，默认 `ubuntu:22.04` + `/workspace`）、
     resume（拒非 Docker state）、delete（no-op，Java 同）、serialize/deserialize_state。
   - `DockerSandbox`：`ensure_container_running`（inspect → 复用/重启/新建）、
     `exec`（`docker exec -w <root> <id> sh -c`，512KB/流截断，超时 -1）、
     `persist_workspace`（`tar -cf -`）、`hydrate_workspace`（`tar -xf -` + stdin 管道 + 双流 drain）、
     `shutdown`（`stop --time=30` + `rm --force`，`container_owned=false` 跳过）、
     `stop`（仅置位 ready，容器保留）、`start`（Java 4 分支的 A/B/D；C 待 snapshot B2）。
2. `state.rs`：`DockerSandboxState` 新增 container_name/container_owned/memory_size_bytes/
   cpu_count/exposed_ports/network/additional_run_args/volumes/workspace_spec，
   `container_id` 改 `Option<String>`，全部 `#[serde(default)]` 兼容旧 JSON；
   `SandboxState` 加 `allow(clippy::large_enum_variant)` 并注释原因。
3. `mod.rs`：`SandboxClientOptions` 增 workspace_root/exposed_ports/additional_run_args；
   `VolumeMount`/`WorkspaceSpec`/`CopySpec` 加 serde；导出 `DockerSandbox`/`DockerSandboxClient`。
4. `filesystem/sandbox.rs`：`kill_process_tree` 提升为 `pub(crate)`（docker 后端复用）。
5. 测试：docker 单测 11（options→state、默认值、resume 校验、JSON round-trip、
   run argv 组装含 limits/ports/volumes/env、shell_quote、workspace_path、无容器报错、
   shutdown no-op）+ `tests/harness_docker_sandbox_test.rs`（daemon 不可用自动跳过）。
