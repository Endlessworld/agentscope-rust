#### 4.5.2 设计决定与已知差异

| 编号 | 项 | Rust 实现 | 与 Java 的差异 | 为何保留（收益/依据） |
|---|---|---|---|---|
| PROTO-X01 | 传输层注入 seam | `JsonRpcTransport`（`client.rs:59-69`，生产实现 `ReqwestJsonRpcTransport:91-134`）+ `CardFetcher`（`card.rs:104-133`） | Java 用 `a2a-java-sdk` 的 `ClientTransport` 类映射 + `HttpClient`，`A2aAgentConfig.clientTransports` 是 map | 单 trait 即可注入、完全离线可测（全部 A2A 用例零网络）；`async fn in trait` 用 boxed future 保持 `Send`，比 SDK 的类反射配置更窄的接缝 |
