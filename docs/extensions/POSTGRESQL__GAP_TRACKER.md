| 锁 key 哈希算法差异 | Java 用 MurmurHash3（`MurmurHash3.hash128(raw.getBytes(UTF_8))[0]`，128 位结果的**低 64 位**）；Rust 用 `DefaultHasher`（SipHash-1-3，`guard.rs:105-107`）。**静态可判定为不一致**：两者是完全不同的哈希族，且 Rust `DefaultHasher` 的输出**不保证跨 Rust 版本稳定**（标准库明确声明），故同前缀下两语言生成的 advisory lock key **不互通**（跨语言混布存在并发互斥失效风险）。Java 的 `raw` 拼接式为 `keyPrefix + scope.name().toLowerCase() + ":" + value`（`IsolationScope` 是枚举），Rust 侧 `scope` 是 `String`（`SandboxIsolationKey.scope`），拼接式等价但**取值空间不同**（Java 仅 4 个枚举值，Rust 为任意字符串） | **已完成（2026-10-29 勘误）**：原记「待确认 / `DefaultHasher` 不互通」，实际已改 Commons Codec 兼容 **MurmurHash3 x64_128 + seed 104729**（`src/murmur3.rs`，金标向量钉住）；依据 history/POSTGRESQL__MIGRATION_HISTORY.md 裁定 6 / `murmur3` 5 用例 |
