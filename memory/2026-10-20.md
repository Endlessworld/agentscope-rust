- **PowerShell 下 rg 通配符必用 `-g`，不要放 path 位置参数**：Windows 的 PowerShell/cmd 不给原生 exe 展开 glob（Linux bash 会先展开成真实路径），而 rg 的位置参数（PATTERN 之后的 path）**永不**做 glob → 收到字面 `*.rs` 直接 `os error 123 文件名/目录名/卷标语法不正确`（与 `$PSNativeCommandArgumentPassing` 无关）。实测推荐写法：
  - `rg <pat> <目录> -g '*.rs'`（最常用，无锚点坑）；`rg --files <目录> -g '*.rs'`
  - 需路径级 glob：**`-g` 写 cwd 相对全路径 + 根固定 `.`**，如 `rg --files -g 'crates/agentscope-core/src/*.rs' .`、`rg 'pub fn' -g 'crates/.../src/**/*.rs' .`
  - 锚点坑：含 `/` 的 glob 匹配的是**相对 cwd 的打印路径**，不是相对搜索根 → `rg --files crates -g 'agentscope-core/src/*.rs'` 返回 0，必须写 `-g 'crates/agentscope-core/src/*.rs'`；`-g` 值用正斜杠（反斜杠不匹配任何文件）。

  - **profile 包装函数不可依赖**：本会话 `execute` 工具总是 `pwsh -NoProfile -EncodedCommand` 启动，`$PROFILE` 不加载 → 自定义 `rg` 函数只对用户交互式终端有效；且「`*.rs` 是 pattern 还是 path glob」存在固有歧义，启发式改写会退化出错，**已裁定不写包装函数**。
