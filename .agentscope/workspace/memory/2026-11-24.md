
## Memory Save — 2026-11-24T13:04:47.865227800+00:00
- ACP 智能体（crates/agentscope-extensions-acp）在 2026-11-21 已落地「执行中追加输入」三件套，全部是私有扩展 `_acp_extends/session/*`：`steer`（折进当前活跃 Turn，返回 {turnId}，无活跃 Turn 时 error data = `no_active_turn`）、`queue`（准入 durable Turn，返回 {turnId, position}，position 1-based）、`queue/list`（{items:[{turnId,position,status}]}，不回正文）、`queue/remove`（{turnId, removed}，已开跑返回 removed:false）、`pause`（{turnId,status}，pausing→paused）、`resume`（等 Turn 收尾才返回，回 {turnId, stopReason}）。
- ACP 语义要点：每个 Turn 的 `session/update` 带 `_meta.turnId`；`session/prompt` 是唯一驱动器（入口先排空遗留 Queued，收尾后再排空一次）；`session/cancel` = 取消当前 Turn + 清空整个队列（client 负责 parked 文本重投）；暂停时 PromptResponse 仍为 `cancelled` 但带 `_meta.paused = true`；暂停不切断已在流式输出的模型消息（仅连续 3s 无输出才切断）。这些都只在 durable 驱动下可用（native/lite 扩展回错误、queue/list 为空）。
